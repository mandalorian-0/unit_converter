# 🚀 Miles to Kilometers Converter

A simple, interactive Python application that converts miles to kilometers using the Tkinter GUI library.

## 📌 Features
- Converts miles to kilometers with precision (1 mile = 1.60934 km)
- Clean, responsive layout with intuitive placement
- Real-time result display after clicking "Calculate"
- User-friendly interface with clear labels and input fields

## 🔧 How It Works
1. Enter the number of miles in the input field.
2. Click the **"Calculate"** button.
3. The result in kilometers appears automatically in the output label.

## 🖥️ UI Layout
- **Input Field**: Enter miles (e.g., 5)
- **"Calculate" Button**: Triggers the conversion
- **Result Label**: Displays kilometers with 2 decimal places
- **Labels**: Clearly indicate units (Miles → Km)

## 📂 Tech Stack
- **Python 3.x**
- **Tkinter** (built-in GUI library)

## 💡 Example Usage
```python
# Input: 5 miles
# Output: 8.05 km
```

## 🚀 How to Run
1. Ensure you have Python 3.x installed.
2. Clone the project

   ```bash 
   git clone https://github.com/mandalorian-0/unit_converter.git
   
   cd unit_converter
   ```
3. Run the script:
   ```bash
   python unit_converter.py
   ```

## 📝 Notes
- The conversion uses the standard conversion factor: 1 mile = 1.60934 km.
- Results are rounded to 2 decimal places for readability.
